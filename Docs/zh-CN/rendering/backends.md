# 图形后端与大场景特性

本页给出后端支持矩阵、能力查询方式，以及依赖后端能力的大场景特性。原则是：能力来自设备查询，不来自后端名字。

## 平台运行时后端

| 后端 | 平台 | 状态 |
| --- | --- | --- |
| DX12 | Windows | 支持的运行时主线 |
| Vulkan 1.1 | Linux / WSL | 支持的运行时主线，WSLg 基线为 `llvmpipe` |
| Metal | macOS | 原生实现与构建目标，非 Apple 平台不支持 |

## 受限后端

| 后端 | 状态 |
| --- | --- |
| DX11 | 显式受限：启动时报告不受支持并正常退出 |
| OpenGL | 显式受限：当前 Windows 构建下启动时报告不受支持并正常退出 |
| Metal（非 Apple） | 不受支持，不通过空设备回退路径暴露 |

这些后端不允许作为交付目标，也不会被静默回退替代。

## 后端能力

每个后端必须显式报告以下能力，编辑器启动与运行时特性选择都读取这些位：

- 交换链
- 离屏帧缓冲
- 帧缓冲回读
- 帧缓冲 blit
- 深度 blit
- UI 纹理句柄
- 立方体贴图
- MRT
- 计算队列
- 拷贝队列
- 显式屏障

能力位只是必要条件；声明某个后端可用还需要当前冒烟验证，以及面向显式后端的 RenderDoc 证据。

## 后端无关的 RHI 约束

- `DriverRendererAccess` 与 `DriverUIAccess` 是受支持的接入点；
- 立即式设备封装已经移除，不应作为新特性的扩展点重新引入；
- 渲染器实例化必须走单一选择入口，让后端选择与渲染器选择保持集中；
- 资源状态转换由 FrameGraph 声明，不靠后端特判。

## 大场景渲染

### 空间索引与可见性

场景维护空间索引，可见性收集以索引查询替代线性扫描。索引重建使用显式遥测、上一份可用数据、脏区标记、分阶段重建或预算控制；不允许多帧同步重建造成不可见的卡顿。

索引维护支持串行、并行与全量扫描对照模式，三条路径必须产出一致的可见集与稀疏句柄输出。

### LOD 与 HLOD

- 静态网格 LOD 在导入阶段构建，运行时只做级别选择；
- LOD/HLOD 决策保持视图局部，不写入共享状态；
- 编辑器选中的 HLOD 子对象必须仍可检查；
- 透明、顺序相关、蒙皮与动画子对象在具备显式代理兼容性之前不参与 HLOD 抑制。

### HZB 遮挡剔除

HZB 遮挡剔除与异步/回读历史选择基于 `RHIDevice::GetCapabilities()` 与纹理格式能力，而不是后端名猜测。

保守性要求：

- 无效、过期、已移动、表示变化、深度不合格或能力受限的历史一律保持可见；
- 普通遮挡帧不引入同步回读、阻塞映射或 CPU/GPU 围栏等待；
- 不支持的能力组合保持保守并记录回退原因。

HZB 的验证方式与所需证据见[可见性与遮挡剔除](../large-scenes/visibility-occlusion.md)。

### 资源驻留

驻留系统区分感兴趣集合与真实驻留集合，去重请求、约束 CPU/GPU 内存与上传预算，并保留帧回收钉子。详见[资源驻留与预算](../large-scenes/streaming.md)。
