# 模型、网格与纹理

本页说明内容管线里两类最常用的资产：模型（含网格与 LOD）与纹理（含 Mip 与压缩）。两者都把导入设置与工件分开保存，修改设置会重新生成工件。

## 模型导入

模型通过 Assimp 导入，支持 glTF、FBX 与 OBJ 等常见格式。一次导入会产生多个子资源：

| 子资源类型 | 说明 |
| --- | --- |
| `Mesh` | 网格几何数据 |
| `Material` | 由模型材质转换而来的材质资产 |
| `Texture` | 模型内嵌或引用的纹理 |
| `Prefab` | 由场景层级生成的 Prefab，标记为生成只读 |

导入后，模型、网格、材质与纹理之间的关系记录在资产数据库与工件清单中，运行时通过资产 ID 解析。

## 材质转换

模型自带的材质会被转换成引擎材质。转换把外部材质描述映射到 StandardPBR 参数集合，生成 `.mat` 材质资产并把纹理接到对应槽位。转换结果是独立资产，可以单独编辑。

## 静态网格 LOD

静态网格支持多级 LOD。导入设置包含：

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| `lodGroup` | `None` | LOD 组预设名 |
| `minLOD` | `0` | 允许使用的最低 LOD 级别 |
| `autoComputeLODScreenSize` | `true` | 是否自动计算各级的屏幕尺寸阈值 |
| `sourceModels` | 每个 LOD 一项 | 每级的来源类型、屏幕尺寸与网格数据 |

每个 LOD 源模型带有来源类型：`Imported`（来自源文件）、`Authored`（在引擎内制作）、`Generated`（由简化流程生成）。

LOD 组预设提供名、级数、三角形比例与像素误差四个字段。同一组预设让多个网格在切换级别时保持一致的手感，避免单个网格各自调阈值。

网格简化在导入阶段完成，运行时不重新计算；运行时只做级别选择，见[图形后端与大场景特性](../rendering/backends.md)。

## 纹理导入设置

纹理导入快照的默认值：

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `textureType` | `default` | 语义类型 |
| `srgbTexture` | `true` | 是否为颜色纹理 |
| `alphaIsTransparency` | `false` | Alpha 是否表示透明度 |
| `mipmapEnabled` | `true` | 是否生成 Mip |
| `maxTextureSize` | `2048` | 最大边长 |
| `resizePolicy` | `keep` | 缩放策略 |
| `compressionIntent` | `default` | 压缩意图 |
| `explicitFormat` | 空 | 显式指定格式 |
| `platformOverrides` | 空 | 逐平台覆盖 |

颜色纹理与线性数据纹理不能混用：颜色纹理走 sRGB 视图，法线与遮挡等数据纹理应关闭 sRGB，否则渲染结果会偏亮或偏灰。

平台覆盖条目可以单独指定最大尺寸、格式、压缩质量、缩放策略与是否生成 Mip，用于在保持源设置的同时为特定平台降规格。

## Mip 与压缩

当前离线工件支持 RGBA8、RGBA16F、BC1、BC3、BC5 与 BC7：

- Windows 编辑器的 `directxtex-bc` 编码器对 BC1、BC3、BC5、BC7 有单元级验证；
- 工件保留目标平台、构建标识、编码器 ID 与版本、数组层与立方体贴图面序等元数据；
- 运行时加载压缩工件前必须确认后端支持该格式，缺少能力时加载失败并给出明确日志，不会静默降级。

BC6H、ASTC4x4 与 ETC2 RGBA8 目前只是格式描述符与注册表上的扩展点。Vulkan、ASTC、ETC2、BC6H、立方体贴图运行时加载与流式 Mip 都需要各自的编码器与后端验证，不能仅凭描述符声明支持。

## 纹理运行时行为

- Mip 生成在导入阶段完成，运行时按采样需求选择级别。
- 压缩纹理的字节按块行复制，上传前会做格式与 sRGB 视图选择。
- 单元测试不替代真实后端抓帧：声明某个格式可运行时，需要在对应平台上做一次实际加载验证。
