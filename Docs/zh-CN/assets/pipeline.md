# Asset Browser 与导入

资产管线把磁盘上的源文件变成运行时可以直接使用、且可追踪来源的数据。Asset Browser 是这层管线的界面，资产数据库是它的实现。

## 资产分层

| 层 | 内容 | 位置 |
| --- | --- | --- |
| 源资产 | 用户提供的文件与脚本，例如模型、纹理、材质、场景、Prefab、C#/Lua 脚本 | `Assets/` |
| 导入元数据 | 每个源资产的标识、版本与导入设置 | 资产数据库 |
| 工件 | 导入生成的运行时数据，带平台与编码器信息 | 内容存储 |
| 清单 | 描述一个资产生成了哪些工件与依赖 | 随工件保存 |

源资产用 GUID 标识而不是路径。移动或重命名文件时引用仍然有效，路径只作为提示与显示。

## Asset Browser

Asset Browser 提供：

- 文件夹、源资产与生成子资源的分层浏览；
- 名称搜索与类型分类；
- 类型图标与异步缩略图；
- 拖放：把资源拖进场景、拖到 Inspector 字段或拖到对象上；
- 对象引用选择器；
- 在 Asset View 面板中打开预览。

缩略图按类型生成：纹理、材质球、模型预览、Prefab 预览与通用图标。生成失败时会记录原因并回退到类型图标，而不是留下空白项。

缩略图与预览受每帧预算与缓存控制，首次导入大型资源时不是同步完成的。

## 导入流程

### 导入一个模型或纹理

前置条件：项目已打开，源文件是[模型、网格与纹理](models-textures.md)列出的受支持格式。

1. 在 Asset Browser 中选择目标目录，用 `Show in explorer` 打开其磁盘位置，或直接打开项目 `Assets/`。
2. 把模型及其依赖纹理复制到该目录，保留模型引用的相对目录结构。复制来源在项目外时，只复制源文件，不复制其他项目的 `Library/`。
3. 回到编辑器，等待资产监听器完成刷新与导入。在 Console 查看失败诊断；大型模型的缩略图可能晚于资产条目出现。
4. 展开模型查看生成的 Prefab/网格/材质子资源，把 Prefab 拖到 Hierarchy。纹理可拖到兼容的材质引用字段。
5. 修改外部源文件并保存可触发增量导入；需要强制重建时右键源资产选择 `Reimport`。生成子资产不能当成独立源文件覆盖。

预期结果：Asset Browser 出现源资产与适用的子资源，模型实例可在场景中选中，Console 没有导入错误。

当前 `Import Here...`、`Create > Scene` 和 `Create > Material` 仍显示为禁用项。导入使用复制到 `Assets/` 的流程；场景从 `File` 菜单新建与保存。改名或移动已有资产时使用编辑器操作并保留其 `.meta` 身份数据，单独移动源文件可能改变引用身份。

```text
源文件变化
  -> 资产监听器标记脏
  -> 选择导入器并按导入设置执行
  -> 生成工件并写入清单
  -> 资产数据库发布新版本
  -> 编辑器刷新引用与预览
```

导入设置按资产保存，改变设置会重新生成工件而不是原地修改。

编辑器提供无界面的预热入口，用于在计时或发布前把导入一次性做完：

```powershell
Tools/Performance/Warm-NullusProjectAssets.ps1 -ProjectPath .\TestProject\TestProject.nullus
```

脚本会完整导入启动源资产并校验可用磁盘空间，一次性迁移耗时不计入启动验收。

## 导入设置存储

纹理与静态网格的导入设置以快照结构保存，字段是显式的、可序列化的：

- 纹理：类型、颜色空间、Alpha、Mip、最大尺寸、缩放策略、压缩意图与逐平台覆盖；
- 静态网格：LOD 组、最小 LOD、是否自动计算 LOD 屏幕尺寸，以及每个 LOD 源模型的类型、屏幕尺寸与网格数据。

具体默认值与影响见[模型、网格与纹理](models-textures.md)。

## 脚本与场景资产

C# 与 Lua 脚本同样作为资产参与管线：

- 保存 C# 脚本触发增量构建，成功后热重载；
- 脚本清单把可序列化字段暴露给编辑器与序列化；
- 场景与 Prefab 是资产，可以由其他资产引用。

详见[脚本系统概览](../scripting/overview.md)。

## 编辑器脚本扩展

项目内的 `Assets/**/Editor/**/*.cs` 会编译成独立的编辑器程序集，只在编辑器进程中加载，可以注册自定义 Inspector 与工具窗口。见[编辑器脚本扩展](../architecture/editor-extensions.md)。
